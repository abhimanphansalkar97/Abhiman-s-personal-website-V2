# Abhiman Phansalkar — Personal Website

## Run locally
1. Open this folder in Visual Studio / VS Code.
2. Double-click `index.html`, or use a Live Server extension.
3. Keep the `assets` folder beside `index.html`.

## Main files
- `index.html` — page content and structure
- `style.css` — visual design and responsive layout
- `script.js` — small interactive behaviours
- `assets/` — supplied personal photos
- `Abhiman_Phansalkar_Resume.pdf` — resume download
